Cómo detectamos la descripción de cada cuadro
01 - Cámara abre en el local.jpg Nombre del archivo: número + descripción separados por guion, guion bajo o punto.
01.jpg + 01.txt Archivo de texto con el mismo nombre: el .txt de cada imagen se usa como descripción.
guion.txt Guion general: un archivo con líneas 01: descripción (o guion.csv / guion.json) describe todos los cuadros de una.
frame_01.png Sin info: si no encontramos nada, el cuadro queda numerado y listo para que escribas la descripción vos, en el momento.
