A

Cambiar precios desde la web

RECOMENDADO

La forma más fácil y segura: editás con el buscador y los nombres a la vista, sin tocar código.

Entrá a tu web agregando ?admin=1 al final de la dirección. Ejemplo: grupodelsurcementera-minorista.netlify.app/?admin=1
Escribí el PIN 1234 y tocá Entrar.
Pantalla del PIN
Ahora cada precio es un casillero editable. Cambiá los números que quieras (usá el buscador de arriba para encontrar un producto rápido).
Cuando terminaste, tocá 📤 Generar / Publicar.
Barra de administración
Se abre un cuadro. Tocá 📋 Copiar y después 🔗 Abrir GitHub.
En GitHub: borrá todo lo que hay en el recuadro, pegá lo que copiaste, y bajá hasta el botón verde Commit changes. Confirmá.
✅ Listo. En ~1 minuto los precios nuevos ya están en las dos webs.
Cuadro "Publicar precios nuevos"
B

Cambiar un precio suelto en GitHub

RÁPIDO

Ideal cuando querés cambiar solo uno o dos precios.

Abrí el link del archivo de precios (precios.json) en GitHub.
Tocá el lápiz ✏️ (arriba a la derecha del archivo) para editar.
Buscá el producto por su nombre y cambiá solo el número: "min" = precio minorista, "may" = precio mayorista.
Tocá el botón verde Commit changes. Listo, se actualiza en ~1 minuto.
  { "id": "001", "cat": "Cementos y Bases", "nom": "Cemento Loma Negra",
    "sub": "Bolsa x 50kg", "min": 6943, "may": 5950 }

Commit changes  ← el botón verde al final para guardar

⚠️ Reglas de oro (para no romper nada)

SÍ ✓Cambiar los números de los precios. NO ✗Borrar las comas ni las comillas.
SÍ ✓Dejar Consultá si un precio no se muestra. NO ✗Cambiar los nombres "min" / "may".
SÍ ✓Poner la fecha en actualizado si querés. NO ✗Tocar el archivo index.html (ese no).
Si algo sale mal, no te preocupes: la web sigue mostrando los últimos precios buenos. Escribile a Lucas y lo dejamos como estaba en 1 minuto.

Preguntas frecuentes

¿Tengo que cambiar las dos webs por separado?
No. El precio minorista ("min") va a la web minorista y el mayorista ("may") a la mayorista, todo desde el mismo archivo.
Cambié el precio y no lo veo.
Esperá 1 minuto y recargá la página (en el celular, deslizá hacia abajo para refrescar).
¿Necesito instalar algo?
No. Solo el navegador del celular o la compu y tu cuenta de GitHub (te la crea Lucas o te suma como colaborador).
